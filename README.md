# MONI updates

Hier halen de MONI-diensten hun updates vandaan. Niet met de hand aanpassen:
`npm run release -- --publish` in Moni-Client en Moni-Server schrijft dit.

- `client/latest.json`: nieuwste MONI (studio-pc's)
- `server/latest.json`: nieuwste MONI Server
- de installers zelf staan bij de releases (`client-x.y.z`, `server-x.y.z`)
